# Сайт АНО «ИДС» — версия 3

Статический многостраничный сайт: HTML + один CSS + один JS, без фреймворков. Шрифты Onest и JetBrains Mono отдаются с самого сайта (без Google Fonts).

**Версия 3** — отдельная копия сайта (боевая версия 2: https://ano-ids.vercel.app, проект Vercel `ano-ids`, её не трогаем).

## Как править и собирать
Исходники лежат в `src/` и `assets/`, готовый сайт собирается в `dist/`:

```
npm install      # шрифты из пакетов Fontsource
npm run build    # node scripts/build.mjs → dist/
```

Нужен Node 18+. Без `npm install` сборка берёт шрифты из `assets/fonts/`. Если шрифта нет ни там, ни в пакетах, сборка остановится с ошибкой.

- `src/pages/*.html` — содержимое страниц; первая строка — заголовок, описание и пункт меню.
- `src/partials/header.html`, `footer.html` — шапка и подвал для всех страниц.
- `assets/img/logo/` — логотип: знак (`mark-*`), надпись «ИДС» (`word-*`) и подпись (`caption-*`), вырезанные из растра `logo/palette/ids-logo-v3.png`. Подпись взята из `logo/palette/ids-logo-v3-fixed.png` (слово «доверенные» собрано из букв самого логотипа). Каждый элемент — две маски WebP: `*-ink` (тёмная часть, на тёмном фоне становится светлой) и `*-teal` (бирюзовая #00B0B2). Чтобы заменить логотип, положите новые маски с теми же именами и поправьте `aspect-ratio` у `.lg-mark`, `.lg-word`, `.lg-cap` в `site.css`. Фавикон — `assets/img/favicon-32.png`.
- `assets/css/site.css` — стили; палитра ИДС в `:root` (источник — `logo/palette/ids-palette.css`).
- `assets/js/site.js` — анимации, меню, форма, копирование реквизитов.
- `scripts/build.mjs` — сборка: подставляет шапку и подвал, копирует ассеты и шрифты.

## Публикация
Vercel: Build Command `npm run build`, Output Directory `dist`, Framework — Other (это же записано в `vercel.json`). Для обновления подключите репозиторий к проекту `ano-ids` или выполните `vercel deploy --prod` из этой папки.

## Что подключить перед запуском
1. **Форма** (`src/pages/contacts.html`): укажите обработчик в `action` (POST: `name`, `org`, `contact`, `task`, `consent`). Скрипт ждёт ответ 2xx. Пока `action` пуст, форма пишет, что отправка не подключена.
2. **Политика ПДн** (`src/pages/privacy.html`): черновик по фактам сайта. Нужны проверка юристом и дата утверждения (в разметке помечено комментарием). Если подключите аналитику или cookies, дополните политику.
3. **E-mail и телефон**: место отмечено комментарием в `contacts.html`.
4. **Документы** (устав, отчёты): шаблон разметки — в комментарии в `documents.html`.
5. **Домен**: сейчас адрес `ano-ids.vercel.app`. После подключения своего домена добавьте `og:url`, `og:image`, `canonical`, `sitemap.xml`, `robots.txt`.

## Motion
Шторка при переходе между страницами (знак-апертура раскрывается), построчное появление заголовков, «поле наблюдения» с рамкой выделения в первом экране, водяной знак, вращающийся при прокрутке, закреплённый сценарий «4 шага», текст, проявляющийся по мере чтения, набор реквизитов, магнитные кнопки, анимированная схема корта (камеры → зрение → трекинг → события). Всё отключается при системной настройке «уменьшить движение».

## Что нового в версии 3
**Палитра.** Серые полупрозрачные тексты заменены оттенками бирюзы (`--ids-foam`, `--ids-foam-2` на тёмном, `--ids-ink-text`, `--ids-ink-soft` на светлом). Все пары «текст/фон» не ниже 4,5:1. Новые темы секций: `theme-mist` (светло-бирюзовая) и `theme-teal` (фирменная бирюза, тёмный текст 6,6:1). Тёмные секции получили мягкое свечение и точечную сетку.

**Стык** — разделитель между крупными блоками: линейка с рамкой-сканером, знак-апертура, вращающийся при прокрутке, и координаты Сколкова. Вставляется одной строкой в странице:
```
<!--seam n="02" label="Принцип работы" theme="dark" k="ЗАДАЧА"-->
```
`theme`: dark | dark-2 | light | mist | teal. Соседние секции автоматически становятся плотнее.

**Мотивы** — графика в пустых колонках: `<div class="motif" data-motif="network" aria-hidden="true"></div>`, варианты `aperture`, `network`, `scan`, `doc`, `orbit`. На десктопе прилипают при прокрутке, на телефоне скрыты.

**Иконки** — `<i class="ico" data-icon="search"></i>` прорисовываются линией при появлении блока. Набор: search, compare, code, launch, chat, team, report, eye, camera, track, event, shield, check, target, layers, key, flag.

**Текст**: `<em class="hl">…</em>` — маркер-выделение, которое «закрашивается» при появлении.

**Нагрузка**: никакого 3D и WebGL. Анимации на transform/opacity и SVG-штрихах; бесконечные анимации идут, только пока блок на экране. При «уменьшить движение» всё статично.

## Юридическая часть — проверить юристом
Тексты политики, согласия, политики cookie и соглашения — проекты, составленные по фактическому устройству сайта. На страницах стоит плашка «Проект»: удалите её после проверки и укажите дату редакции. Что нужно решить:
1. **Хостинг.** Vercel — американская компания. Юристу нужно оценить трансграничную передачу (ст. 12 152-ФЗ) или перенести сайт на российский хостинг.
2. **Обработчик формы** должен хранить заявки на серверах в РФ (ч. 5 ст. 18 152-ФЗ).
3. **Уведомление Роскомнадзора** об обработке ПДн (ст. 22), если его ещё не подавали.
4. **E-mail для обращений по ПДн** — места отмечены комментариями в `privacy.html` и `consent.html`.
5. **Сроки хранения** заявок (сейчас «не более 1 года») — согласовать.
6. Если подключите Яндекс Метрику или cookie — до запуска счётчика нужен баннер с согласием и правка политик.
