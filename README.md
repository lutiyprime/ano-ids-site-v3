# Сайт АНО «ИДС» — версия 3

Статический многостраничный сайт: HTML + один CSS + один JS, без фреймворков. Шрифты Onest и JetBrains Mono отдаются с самого сайта (без Google Fonts).

Production: https://ano-ids-v3.vercel.app (проект Vercel `itsst/ano-ids-v3`). Другие версии сайта удалены.

## Как править и собирать
Исходники лежат в `src/` и `assets/`, готовый сайт собирается в `dist/`:

```
npm install      # шрифты из пакетов Fontsource
npm run build    # node scripts/build.mjs → dist/
```

Нужен Node 18+. Без `npm install` сборка берёт шрифты из `assets/fonts/`. Если шрифта нет ни там, ни в пакетах, сборка остановится с ошибкой.

- `src/pages/*.html` — содержимое страниц; первая строка — заголовок, описание и пункт меню.
- `src/partials/header.html`, `footer.html` — шапка и подвал для всех страниц.
- **Логотип** — векторный, из актуального файла `logo/ids-logo-source.webp` (ноябрь 2026), обведён potrace. `src/partials/logo-sprite.svg` — спрайт из трёх символов: знак `lg-mark`, «ИДС» `lg-word`, подпись `lg-cap`; тёмная часть — `currentColor` (`--lg-ink`, на тёмном фоне светлая), бирюза — `--lg-teal`. Сборка встраивает спрайт в каждую страницу, а в разметке логотип пишется как `<span class="lg lg-mark …"></span>` — при сборке он становится `<svg><use href="#lg-mark"/></svg>`. Логотип рисуется с первого кадра, без загрузки картинок. Полный цветной логотип для документов — `assets/img/logo/ids-logo.svg`; фавиконки — `assets/img/favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`. Чтобы заменить логотип, обновите спрайт и `aspect-ratio`/`transform-origin` у `.lg-*` в `site.css`.
- `assets/css/site.css` — стили; палитра ИДС в `:root` (источник — `logo/palette/ids-palette.css`).
- `assets/js/site.js` — анимации, меню, форма, копирование реквизитов.
- `scripts/build.mjs` — сборка: подставляет шапку и подвал, копирует ассеты и шрифты.

## Публикация
Vercel: Build Command `npm run build`, Output Directory `dist`, Framework — Other (это же записано в `vercel.json`). Версия 3 подключена к проекту Vercel `ano-ids-v3` через GitHub (`lutiyprime/ano-ids-site-v3`): пуш в `main` публикует https://ano-ids-v3.vercel.app.

## Что подключить перед запуском
1. **Форма** (`src/pages/contacts.html`): укажите обработчик в `action` (POST: `name`, `org`, `contact`, `task`, `consent`). Скрипт ждёт ответ 2xx. Пока `action` пуст, форма пишет, что отправка не подключена.
2. **Политика ПДн** (`src/pages/privacy.html`): черновик по фактам сайта. Нужны проверка юристом и дата утверждения (в разметке помечено комментарием). Если подключите аналитику или cookies, дополните политику.
3. **E-mail и телефон**: место отмечено комментарием в `contacts.html`.
4. **Документы** (устав, отчёты): шаблон разметки — в комментарии в `documents.html`.
5. **Домен**: сейчас адрес `ano-ids-v3.vercel.app`. После подключения своего домена добавьте `og:url`, `og:image`, `canonical`, `sitemap.xml`, `robots.txt`.

## Motion
Шторка при переходе между страницами с полным логотипом (знак делает оборот, «ИДС» и подпись проявляются), построчное появление заголовков, «поле наблюдения» с рамкой выделения в первом экране, водяной знак, вращающийся при прокрутке, закреплённый сценарий «4 шага», текст, проявляющийся по мере чтения, набор реквизитов, магнитные кнопки, сцена «удар по мячу» из точек на главной и анимированная схема корта на странице проекта. Всё отключается при системной настройке «уменьшить движение».

**Переход между страницами.** По клику шторка поднимается, знак делает полуоборот (0 → −180°, `HALF` = 560 мс в `site.js`, `curtHalf` в `site.css`) и останавливается — в этот момент начинается переход. Новая страница видит отметку `ids-tr` в `sessionStorage`, скрипт в `<head>` ставит `html.tr`, и знак с первого кадра доводит оборот до −360° (`curtHalf2`), а шторка уходит. Пока браузер грузит страницу, знак стоит, поэтому пауза любой длины не даёт рывка (раньше переход начинался на пике скорости вращения, а маски логотипа перезагружались — отсюда были остановка и «перезапуск»). При наведении на внутреннюю ссылку страница предзагружается (`<link rel=prefetch>`), переход почти мгновенный. При первом заходе в сессию — заставка: знак вкручивается, «ИДС» и подпись проявляются. Знак вращается вокруг центра апертуры (`transform-origin` у `.lg-mark`).

**Сцена «удар по мячу»** (главная, блок 04; `data-swing`, компонент `Swing` в `site.js`). Сетка точек, как в первом экране, складывается в игрока с ракеткой для падела; прокрутка ведёт замах и удар. Затем поверх появляется то, что «видят» камеры, по шагам конвейера: камеры → рамки и скелет позы → траектории мяча и ракетки с координатами на осях в метрах → события «удар» и «отскок». На десктопе секция закрепляется (300vh), на телефоне сцена идёт по мере прохождения блока. При «уменьшить движение» — один статичный кадр со всеми слоями. Позы задаются ключами `KEYS`, мяч — функцией `ballAt`. Это иллюстрация принципа, а не запись игры и не результат алгоритма (подпись под схемой).

**Блок «Связаться» (CTA)**: фон `theme-mist` с линейкой сверху и точечной сеткой справа; заголовок «захвачен» рамкой выделения с подписью (`<div class="cta-frame" data-frame data-k="Ваша задача">`). Рамка подгоняется под фактические строки и сжимается один раз при появлении. Бирюзовая заливка `theme-teal` для CTA больше не используется: она совпадала с цветом лепестка логотипа.

## Что нового в версии 3
**Палитра.** Серые полупрозрачные тексты заменены оттенками бирюзы (`--ids-foam`, `--ids-foam-2` на тёмном, `--ids-ink-text`, `--ids-ink-soft` на светлом). Все пары «текст/фон» не ниже 4,5:1. Новые темы секций: `theme-mist` (светло-бирюзовая) и `theme-teal` (фирменная бирюза, тёмный текст 6,6:1). Тёмные секции получили мягкое свечение и точечную сетку.

**Меню в шапке** — четыре пункта: Услуги, Проекты, О нас, Контакты. Команда и Документы — в мобильном меню, подвале и на странице «О нас»; на этих страницах в шапке подсвечен пункт «О нас» (`NAV_PARENT` в `scripts/build.mjs`).

**Кнопки**: стрелка при наведении сдвигается, а не удлиняется — ширина кнопки не меняется (иначе в узких рядах кнопка перескакивала на новую строку и мигала). Статус формы — отдельной строкой под кнопкой.

**Стык** — разделитель между крупными блоками: линейка с рамкой-сканером и координаты Сколкова (знак-логотип из стыка убран — вращение знака оставлено для перехода между страницами). Вставляется одной строкой в странице:
```
<!--seam n="02" label="Принцип работы" theme="dark" k="ЗАДАЧА"-->
```
`theme`: dark | dark-2 | light | mist | teal. Соседние секции автоматически становятся плотнее.

**Мотивы** — графика в пустых колонках: `<div class="motif" data-motif="network" aria-hidden="true"></div>`, варианты `aperture` (сканер: луч обходит круг, точки вспыхивают), `signal` (точка на карте с расходящимися кругами — на контактах), `network`, `scan`, `doc`, `orbit`. На десктопе прилипают при прокрутке, на телефоне скрыты. Двигаются медленными бесконечными циклами, только пока на экране; при «уменьшить движение» стоят.

**Иконки** — `<i class="ico" data-icon="search"></i>` прорисовываются линией при появлении блока. Набор: search, compare, code, launch, chat, team, report, eye, camera, track, event, shield, check, target, layers, key, flag.

**Текст**: `<em class="hl">…</em>` — маркер-выделение, которое «закрашивается» при появлении.

**Нагрузка**: никакого 3D и WebGL. Анимации на transform/opacity, SVG-штрихах и Canvas 2D; сцена «удар по мячу» перерисовывается только при прокрутке; бесконечные анимации идут, только пока блок на экране. При «уменьшить движение» всё статично.

**Редакция motion (v3.1)**: убрана бегущая строка с реквизитами под первым экраном (дублировала строку фактов и подвал); знак-логотип убран из стыков и CTA (логотип остаётся в шапке, первом экране, подвале и на шторке); пульсация точки в стыках убрана; сценарий «4 шага» короче (300vh вместо 380vh); у текста с проявлением исходная непрозрачность 0,3 вместо 0,16 — его можно читать до прокрутки.

## Юридическая часть — проверить юристом
Тексты политики, согласия, политики cookie и соглашения — проекты, составленные по фактическому устройству сайта. На страницах стоит плашка «Проект»: удалите её после проверки и укажите дату редакции. Что нужно решить:
1. **Хостинг.** Vercel — американская компания. Юристу нужно оценить трансграничную передачу (ст. 12 152-ФЗ) или перенести сайт на российский хостинг.
2. **Обработчик формы** должен хранить заявки на серверах в РФ (ч. 5 ст. 18 152-ФЗ).
3. **Уведомление Роскомнадзора** об обработке ПДн (ст. 22), если его ещё не подавали.
4. **E-mail для обращений по ПДн** — места отмечены комментариями в `privacy.html` и `consent.html`.
5. **Сроки хранения** заявок (сейчас «не более 1 года») — согласовать.
6. Если подключите Яндекс Метрику или cookie — до запуска счётчика нужен баннер с согласием и правка политик.
